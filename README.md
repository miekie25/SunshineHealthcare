# Sunshine Healthcare

## What it is
A modern website built to promote a nurse's services - Sunshine Health Care, a community clinic in Carletonville, South Africa.

## Main pages and sections
- **Home** - Hero with call/WhatsApp buttons and clinic overview
- **About** - Information about the clinic and Nurse Practitioner
- **Services** - Overview of services offered (IV/drip therapy, baby wellness & immunisation, basic assessments, family clinic, wound clinic)
- **Drips** - Vitalize drip menu with a booking form that generates a WhatsApp message
- **Practitioner** - Information about PNP Sylvia P Mngadi
- **Contact** - Contact details, operating hours, location, and map

## Technologies used
- HTML
- CSS
- JavaScript

## How to run it
Open index.html in a browser.
